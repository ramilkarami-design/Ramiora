RAMIORA — VERSION 1

Установка:
1. Распакуй ZIP в отдельную папку.
2. Открой Chrome: chrome://extensions
3. Включи «Режим разработчика».
4. Отключи предыдущую версию Ramiora, если она установлена.
5. Нажми «Загрузить распакованное расширение» и выбери папку с файлами проекта.
6. Открой новую вкладку Ctrl+T.

Яндекс Браузер:
1. Сделай копию всей папки проекта, чтобы не менять сборку для Chrome.
2. В копии замени manifest.json файлом manifest.yandex.json и переименуй его в manifest.json.
3. Открой browser://extensions и включи режим разработчика.
4. Нажми «Загрузить распакованное расширение» и выбери папку-копию.
5. Нажми на значок Ramiora на панели расширений — страница откроется в новой вкладке. Ctrl+T останется стандартной новой вкладкой Яндекс Браузера.

Яндекс Браузер отклоняет настройку chrome_url_overrides, которая нужна для замены страницы Ctrl+T. Поэтому для него используется отдельный манифест без этой настройки. Установку нужно выполнить отдельно в каждом браузере; настройки и быстрые ссылки между Chrome и Яндекс Браузером автоматически не переносятся.

В этой версии используются отдельные исходники:
- background.png — отдельный фон;
- zhongli-lord.png — персонаж по умолчанию с прозрачностью;
- winter-tsaritsa.png и winter-moon-express.png — персонаж и фон темы «Вечная зима»;
- theme-winter.jpg — неизменённое изображение карточки темы «Вечная зима»;
- HTML/CSS — интерфейс, панели и интерактивные зоны.

Работает: часы, дата, поиск Google и Яндекс, переход в ChatGPT, голосовой ввод (если поддерживается Chrome), погода через wttr.in (по заданному городу или по автоопределению сервиса), быстрые ссылки, настройки приветствия, темы и игра-пятнашки.

Пятнашки каждый день выбирают новое изображение из папки puzzles. Список JPG-файлов хранится в puzzles/index.json; чтобы добавить изображение в игру, положи его в puzzles и добавь его имя в этот список.

Для получения погоды расширение обращается к wttr.in; для этого домена запрошено сетевое разрешение в manifest.json.

Конфиденциальность:
- В исходниках нет IP-адреса автора; имя и почта разработчика указаны в подписи настроек. В метаданных изображений не обнаружены GPS-координаты или данные автора.
- Настройки расширения сохраняются локально в браузере.
- Для погоды отправляется запрос к wttr.in. При автоопределении сервис получает IP-адрес посетителя и может определить местоположение; при заданном городе город передается в запросе. Даже при заданном городе сервер видит IP-адрес запроса.
- При выборе Google значки приложений автоматически загружаются с серверов Google, которые видят IP-адрес посетителя. Поисковые запросы передаются выбранной поисковой системе только после отправки формы; сайты открываются по нажатию на ссылку.

Если после установки Chrome показывает старую страницу, обнови расширение на chrome://extensions и открой новую вкладку.
